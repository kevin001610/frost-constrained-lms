基礎 1

寬頻陣列：K 個感測器 × J 個抽頭

Frost 的陣列是 K 個等間距的感測器，每個感測器後面接一條 J 個抽頭的延遲線，抽頭間隔 τ，所以一共有 KJ 個權重。平面波從偏離正前方 θ 的方向進來時，相鄰感測器多一段 τ·sinθ 的傳播延遲；再往延遲線走，每個抽頭又多 τ。下表列出每個抽頭看到的總延遲（以 τ 為單位）。陣列已經對準看向方向 θ = 0°，所以訊號在同一個直行上的延遲完全相同。

相鄰感測器延遲

每格是感測器 k、抽頭 j 的延遲 (k−1)·sinθ + (j−1)。θ = 0° 時每一直行四格一樣，整個陣列對這個方向等效於一條四抽頭的 FIR 濾波器，等效權重 fj 就是第 j 直行四個權重的和。把 θ 拉開，直行就不再相同，陣列靠這個差別分辨方向。

這就是 J 條約束的來源：只要固定每一直行權重的和 fj，看向方向的頻率響應就被鎖住；剩下 KJ − J 個自由度拿去最小化總輸出功率。訊號與雜訊不相關時，總功率等於訊號功率加雜訊功率，而訊號功率已經被鎖定，所以最小化總功率就等於最小化雜訊功率。

對照程式：權重索引與約束矩陣 
n  = (1:S.N)';                 % 權重索引 n = j*K + k + 1（直行優先，和 C 一致）
kk = mod(n-1, S.K);            % 感測器 0..K-1
jj = floor((n-1)/S.K);         % 抽頭 0..J-1
S.C = kron(eye(S.J), ones(S.K,1));        % KJ×J，c_j 挑出第 j 直行
S.P = eye(S.N) - S.C*((S.C'*S.C)\S.C');   % 式 (20b)
S.F = S.C*((S.C'*S.C)\S.Fvec);            % 式 (20a)，也是 W(0)
程式一 · SETUP

從 Table I 重建 Rxx

論文的模擬有三個點源：看向方向的訊號（功率 0.1、0°、中心頻率 0.3、頻寬 0.1）、雜訊 A（1.0、45°、0.2、0.05）、雜訊 B（1.0、60°、0.4、0.07），每個抽頭再加 0.1 的白雜訊；頻率以 1/τ 為 1。論文說所有時間相關在時差大於 25τ 時恰為零，程式用一個 25τ 的三角窗乘上帶通相關來實現這一點：

r(t) = P · (1 − |t|/25) · sinc(B t) · cos(2π fc t)，　|t| ≤ 25τ

三角窗、sinc 與餘弦各自都是合法的相關函數，乘積仍是合法的相關函數，所以 Rxx 保證正定。抽頭 a 與抽頭 b 的相關就是 r 在它們延遲差上的值，三個源相加，再在對角線加上白雜訊。

16 個特徵值由小到大。論文印的是 0.111 到 8.355：用三角窗時兩端都對上了；拿掉窗，最小值掉回白雜訊功率 0.100，最大值也偏離，所以「相關在 25τ 外為零」這句話是重建模型的關鍵。PRxxP 恰有 J = 4 個零特徵值，其餘介於 λmin 與 λmax 之間。

程式一 · 最佳解

約束鎖住的響應，與它能到的最低功率

看向方向的頻率響應只由向量 𝓕 = [f1 … fJ]T 決定，論文取 [1, −2, 1.5, 2]。把約束用拉格朗日乘數併入成本函數，梯度為零、代回約束，就得到最佳受限權重和它的輸出功率：

Wopt = R−1C ( CTR−1C )−1 𝓕 ，　E[yopt²] = 𝓕T ( CTR−1C )−1 𝓕

|H(f)|² = |Σj fj e−i2πf(j−1)|²，對照論文 Fig. 9。這條曲線不管權重怎麼調都不會變，因為每一直行的和被約束固定了。

最佳解與性能界

初始權重 F = C(CTC)−1𝓕 只滿足約束、不壓雜訊，所以它的輸出功率最高；最佳解把雜訊壓到底。失調量是穩態輸出功率超出最佳值的比例，由式 (27) 給上下界；μ 愈小失調量愈小，但最慢模式的時間常數 1/(μσmin) 愈長。論文：μ = 0.01 時 15.2–17.0 %。

μ 有兩個不同的上界。平均權重 E[W(k)] 只要 μ < 2/σmax 就收斂；論文寫的 1/σmax 是讓誤差被兩條遞減等比數列夾住的充分條件，不是發散門檻。權重的變異（也就是輸出功率）要 μ 小於式 (26) 才保證收斂，這個界小得多。在這個模型上用 100 次獨立模擬實測：μ = 0.047 時穩態平均輸出功率已是最佳值的 9 倍，μ = 0.05 時約 23 倍，μ ≥ 0.055 就發散，所以式 (26) 的 0.047 幾乎就是均方失穩的邊緣。論文說式 (26) 算出 0.074，但代入它自己的數字只得到 0.047；0.074 恰好等於 2/tr(PRxxP)，也就是式 (26) 的分母少了 σmax，推測是原文計算時漏掉了這一項。論文實際用的 μ = 0.01 遠小於兩者，不影響結論。

對照程式：Wopt 與式 (25)–(28) 
RiC    = S.Rxx \ S.C;
S.Wopt = RiC * ((S.C'*RiC) \ S.Fvec);           % 式 (16)
S.Popt = S.Fvec' * ((S.C'*RiC) \ S.Fvec);       % 最佳輸出功率 2.4954

PRP      = S.P*S.Rxx*S.P;
S.sigma  = sort(eig(PRP)); S.sigma = S.sigma(S.J+1:end);   % 去掉 J 個零特徵值
S.mu_max26 = 1/(max(S.sigma) + 0.5*trace(PRP));           % 式 (26)
S.mu_max28 = 2/(3*trace(S.Rxx));                           % 式 (28)
S.M_lo = (mu/2)*trace(PRP) / (1 - (mu/2)*(trace(PRP) + 2*min(S.sigma)));  % 式 (27)
S.M_hi = (mu/2)*trace(PRP) / (1 - (mu/2)*(trace(PRP) + 2*max(S.sigma)));
程式二 · ADAPT

走一步、投影、加回 F

實際上 Rxx 不知道，演算法只能用當下的抽頭電壓 X(k) 與輸出 y(k)。Frost 把未知的 RxxW 換成瞬時估計 X(k)y(k)，再讓每一步都回到約束平面：

受限 LMS　W(k+1) = P [ W(k) − μ y(k) X(k) ] + F ，　W(0) = F
梯度投影法　W(k+1) = W(k) − μ P y(k) X(k)

模擬控制

算術精度（有效數字）

輸出功率 WT(k) Rxx W(k)（對照論文 Fig. 11、Fig. 12 上圖）

兩種演算法吃完全相同的一組快照。實線是最佳輸出功率，兩條虛線是最佳值加上式 (27) 的失調量上下界。輸出功率從 W(0) = F 的值一路往下掉，穩態在界附近抖動；兩條曲線幾乎重合，因為梯度投影法的誤差還沒把約束平面推離原點多遠。

約束誤差 ‖CTW(k) − 𝓕‖²（對照 Fig. 11、Fig. 12 下圖，對數刻度）

誤差恰為零的點畫在圖的底線上。雙精度下受限 LMS 的約束誤差是 10−30 等級，梯度投影法的誤差也只能從捨入慢慢長出來，所以要看出差別就得像論文一樣用短位數的算術。6 位有效數字時，受限 LMS 停在 10−12 附近不動，梯度投影法像隨機漫步一樣往上爬。切到線性刻度就是論文的畫法：受限 LMS 的誤差貼在零上，根本看不見，這就是 Fig. 12 圖說「Note scale」要強調的事。

  • 按「播放收斂過程」，輸出功率在大約 30 次更新內掉到界附近；下方的約束誤差，橘線在 6 位數算術下從第一步就開始累積。
  • 把 N 拉到 2000：梯度投影法的誤差比起頭大上幾個數量級，受限 LMS 仍然是一條平的。這就是論文「可以無限期運行」的意思。
  • 把 μ 調大：收斂變快、穩態抖動變大，失調量的界也跟著往上；拉到 0.05（超過式 (26) 的 0.047）時，式 (27) 的上界失效，輸出功率偶爾會衝到很高；再大一點（約 0.055）就會發散，所以滑桿停在 0.05。
  • 切到「4 位」：捨入誤差放大一萬倍，梯度投影法的偏差很快就看得見，受限 LMS 仍每一步被拉回來。
對照程式：受限 LMS 與梯度投影法的主迴圈 
W = q(S.F);                              % W(0) = F；q() 把每個值四捨五入到 6 位有效數字
for k = 1:Nsnap
    x    = X(:, k);
    y(k) = q(W' * x);                    % 陣列輸出
    g    = q(mu * y(k) * x);             % μ × 瞬時梯度估計
    switch lower(algo)
        case 'clms'
            W = q(q(S.P * q(W - g)) + S.F);   % 式 (22)：投影，再加 F
        case 'gp'
            W = q(W - q(S.P * g));             % 式 (31)：只加投影後的梯度
    end
    Wh(:, k+1) = W;
end
out.Pout = sum(Wh .* (S.Rxx * Wh), 1);   % 真實輸出功率 Wᵀ R W
E        = S.C' * Wh - S.Fvec;
out.cerr = sum(E.^2, 1);                 % 約束誤差 ‖CᵀW − 𝓕‖²
程式二 · 結果

雜訊去哪了：把輸出功率拆開來看

論文只畫了總輸出功率。它從 W(0) = F 的值掉到接近最佳值，但光看總功率，看不出訊號有沒有被保住、被壓掉的又是哪一個雜訊。三個點源彼此不相關，白雜訊在各抽頭之間也獨立，所以輸出功率剛好可以拆成四項相加：

WTRxxW = WTR訊號W + WTRAW + WTRBW + σw² ‖W‖²

各來源的輸出功率（中間一列跟隨上方「已更新次數 k」）

看向方向訊號雜訊 A（45°）雜訊 B（60°）白雜訊 σw²‖W‖²

訊號那一段在三列都一樣長：約束鎖住了看向方向的響應，演算法碰不到它。被壓下去的是兩個方向性雜訊（論文設定下 A 約降 13 dB、B 約降 10 dB），輸出 SNR 因此提高約 8 dB。白雜訊反而變大：要在 45° 與 60° 挖出零點，權重必須拉大（‖W‖² 從 2.81 變成 4.01），而白雜訊的輸出功率正比於 ‖W‖²。這是形成零點的代價，也是後來的強健波束成形要加對角載入（diagonal loading）來限制 ‖W‖² 的原因。

程式二 · 收斂

平均權重以幾何級數靠近最佳解

把更新式取期望，再減掉 Wopt，差向量 V(k) = E[W(k)] − Wopt 每一步乘上 I − μPRxxP。沿著 PRxxP 的每個特徵向量，收斂都是比值 (1 − μσi) 的幾何級數，所以整體被夾在最快與最慢兩條幾何曲線之間：

(1 − μσmax)k ‖V(0)‖ ≤ ‖V(k)‖ ≤ (1 − μσmin)k ‖V(0)‖
μ 跟隨上方「模擬控制」的設定

青綠線是 ‖E[W(k)] − Wopt‖ 除以初始距離，用獨立模擬的樣本平均估計；兩條虛線是理論上的快慢界。初始差向量主要落在大特徵值的方向上，所以一開始掉得快，之後被最慢的模式（時間常數約 1/(μσmin) ≈ 900 次）拖住。

對照程式：驗證式 (24) 
L = chol(S.Rxx, 'lower');
for n = 1:Nrun
    Xn = L*randn(S.N, Nit);                      % 獨立高斯快照
    rr = frost1972_adapt(S, Xn, S.mu, 'clms', []);
    Wmean = Wmean + rr.W/Nrun;
end
PRP = S.P*S.Rxx*S.P; Vpred = zeros(S.N, Nit+1); Vpred(:,1) = S.F - S.Wopt;
for k = 1:Nit, Vpred(:,k+1) = Vpred(:,k) - S.mu*PRP*Vpred(:,k); end      % 式 (24)
errpred = max(sqrt(sum((Wmean - S.Wopt - Vpred).^2, 1)))/dev0;
check(errpred < 0.05, 'ensemble mean E[W(k)] follows eq. (24) ...', errpred);
程式二 · 集成驗證

把論文的兩個定量說法拿來檢驗

單次模擬只能看出「趨勢像」。下面兩個實驗用多次獨立模擬的平均，直接檢驗 Sec. IV 的失調量公式 (27)，以及 Sec. VI「梯度投影法的偏差像隨機漫步，期望平方距離隨更新次數線性成長」這句話。兩者固定使用論文設定（三角窗模型、白雜訊 0.1、𝓕 = [1, −2, 1.5, 2]），不受上面的控制項影響；頁面載入後會在背景計算。

穩態失調量：實測與式 (27) 的上下界

每個 μ 跑 40 次獨立模擬（雙精度），先跑過暫態（max(1500, 12/μ) 次），再對之後 3000 次更新的輸出功率 WTRxxW 取平均，換算成失調量 M = 平均輸出功率 / 最佳輸出功率 − 1。論文只在 μ = 0.01 給了一組界；這裡把 μ 掃過一段範圍。小 μ 時上下界幾乎重合（μ = 0.0025 時只差 0.07 個百分點），所以用「實測 ± 2 個標準誤是否和界重疊」來判斷；μ 愈大，實測愈貼近上界。

約束誤差的集成平均：梯度投影法真的是隨機漫步嗎

6 位數的捨入規則

40 次獨立模擬、6 位有效數字、μ = 0.01，兩種演算法吃同一組快照；為了看清楚，每一段對數區間內的點先取平均。隨機漫步的期望平方距離與 k 成正比，在 log–log 圖上是斜率 1 的直線（灰色虛線）。

兩個演算法的差別只是式 (19) 最後一項 C(CTC)−1[𝓕 − CTW(k)]：完美算術下它是零，可以丟掉；數位實作下它就是自我修正。受限 LMS 的限制也和這一頁的假設綁在一起：它假設非看向方向的雜訊與訊號不相關，多路徑或同調雜波會讓處理器用訊號的複本把訊號本身抵消掉（這是另一支程式〈相干訊號與空間平滑〉處理的題目）；實作誤差則會讓它在字面上滿足約束、實際上壓掉訊號。
