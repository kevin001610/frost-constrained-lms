基礎 1

寬頻陣列：K 個感測器 × J 個抽頭

Frost 的陣列是 K 個等間距的感測器，每個感測器後面接一條 J 個抽頭的延遲線，抽頭間隔 τ，所以一共有 KJ 個權重。平面波從偏離正前方 θ 的方向進來時，相鄰感測器多一段 τ·sinθ 的傳播延遲；再往延遲線走，每個抽頭又多 τ。下表列出每個抽頭看到的總延遲（以 τ 為單位）。陣列已經對準看向方向 θ = 0°，所以訊號在同一個直行上的延遲完全相同。

相鄰感測器延遲

每格是感測器 k、抽頭 j 的延遲 (k−1)·sinθ + (j−1)。θ = 0° 時每一直行四格一樣，整個陣列對這個方向等效於一條四抽頭的 FIR 濾波器，等效權重 fj 就是第 j 直行四個權重的和。把 θ 拉開，直行就不再相同，陣列靠這個差別分辨方向。

這就是 J 條約束的來源：只要固定每一直行權重的和 fj，看向方向的頻率響應就被鎖住；剩下 KJ − J 個自由度拿去最小化總輸出功率。訊號與雜訊不相關時，總功率等於訊號功率加雜訊功率，而訊號功率已經被鎖定，所以最小化總功率就等於最小化雜訊功率。

對照程式：權重索引與約束矩陣 
n  = (1:S.N)';                 % 權重索引 n = j*K + k + 1（直行優先，和 C 一致）
kk = mod(n-1, S.K);            % 感測器 0..K-1
jj = floor((n-1)/S.K);         % 抽頭 0..J-1
S.C = kron(eye(S.J), ones(S.K,1));        % KJ×J，c_j 挑出第 j 直行
S.P = eye(S.N) - S.C*((S.C'*S.C)\S.C');   % 式 (20b)
S.F = S.C*((S.C'*S.C)\S.Fvec);            % 式 (20a)，也是 W(0)

論文說所有時間相關在時差大於 25τ 時恰為零，但沒有給相關函數的形式。程式用一個 25τ 的三角窗乘上帶通相關來實現這一點：

r(t) = P · (1 − |t|/25) · sinc(B t) · cos(2π fc t)，　|t| ≤ 25τ

三角窗、sinc 與餘弦各自都是合法的相關函數，乘積仍是合法的相關函數，所以 Rxx 保證正定。抽頭 a 與抽頭 b 的相關就是 r 在它們延遲差上的值，三個源相加，再在對角線加上白雜訊。

入射訊號的功率頻譜（對照論文 Fig. 10）

三個源的功率頻譜，由上式做餘弦轉換得到；虛線是每個抽頭上白雜訊的功率位準。訊號只有 0.1 的功率，在論文的線性刻度下幾乎貼在橫軸上；切到 dB 才看得出它的頻帶落在 0.25–0.35。三角窗讓頻譜的邊緣變圓、裙邊抬高，這和論文 Fig. 10 的形狀一致。

Rxx 的特徵值範圍

論文：「the eigenvalues of Rxx ranged from 0.111 to 8.355」。用上面的模型重建，兩端都對上了，這也是相關函數形式可以採用三角窗模型的依據。

對照程式：相關函數與 Rxx 
function r = frost1972_acf(t, fc, B, Tc)
r = (1 - abs(t)/Tc) .* sinc(B*t) .* cos(2*pi*fc*t);
r(abs(t) > Tc) = 0;
end

R = zeros(S.N);
for m = 1:numel(S.src)
    d   = sind(S.src(m).theta);            % 相鄰感測器延遲（τ）
    lag = (jj - jj') + (kk - kk')*d;        % 抽頭 a、b 的延遲差
    R   = R + S.src(m).P * frost1972_acf(lag, S.src(m).fc, S.src(m).B, S.Tc);
end
R = R + S.Pwhite*eye(S.N);
S.lambda = sort(eig(S.Rxx));                % 0.1110 ... 8.3556
程式一 · 最佳解

Fig. 9 的看向方向響應，與 μ = 0.01 的性能界

看向方向的頻率響應只由向量 𝓕 = [f1 … fJ]T 決定，論文取 𝓕T = [1, −2, 1.5, 2]。把約束用拉格朗日乘數併入成本函數，梯度為零、代回約束，就得到最佳受限權重和它的輸出功率：

Wopt = R−1C ( CTR−1C )−1 𝓕 ，　E[yopt2] = 𝓕T ( CTR−1C )−1 𝓕

看向方向的頻率響應（對照論文 Fig. 9）

|H(f)|2 = |Σj fj e−i2πf(j−1)|2，𝓕T = [1, −2, 1.5, 2]。這條曲線不管權重怎麼調都不會變，因為每一直行權重的和被約束固定了；它的峰值落在 f ≈ 0.32，正好蓋住訊號的頻帶。

論文 Sec. VII 的數字（μ = 0.01）

處理器從 W(0) = F = C(CTC)−1𝓕 開始：它只滿足約束、不壓雜訊，所以輸出功率最高；最佳解把雜訊壓到底。失調量是穩態輸出功率超出最佳值的比例，論文用式 (27) 算出 μ = 0.01 時介於 15.2 % 與 17.0 %，這兩個界就是 Fig. 11 上圖裡靠得很近的兩條水平線。

唯一對不上的是式 (26)：論文說算出來的 μ 上界是 0.074，但代入它自己的模型只得到 0.047。0.074 恰好等於 2/tr(PRxxP)，也就是式 (26) 的分母少了 σmax，推測是原文計算時漏掉了這一項。論文實際用的 μ = 0.01 遠小於兩者，不影響結論。

對照程式：Wopt 與式 (26)、(27) 
RiC    = S.Rxx \ S.C;
S.Wopt = RiC * ((S.C'*RiC) \ S.Fvec);           % 式 (16)
S.Popt = S.Fvec' * ((S.C'*RiC) \ S.Fvec);       % 最佳輸出功率 2.4954

PRP      = S.P*S.Rxx*S.P;
S.sigma  = sort(eig(PRP)); S.sigma = S.sigma(S.J+1:end);   % 去掉 J 個零特徵值
S.mu_max26 = 1/(max(S.sigma) + 0.5*trace(PRP));           % 式 (26)
S.M_lo = (mu/2)*trace(PRP) / (1 - (mu/2)*(trace(PRP) + 2*min(S.sigma)));  % 式 (27)
S.M_hi = (mu/2)*trace(PRP) / (1 - (mu/2)*(trace(PRP) + 2*max(S.sigma)));
程式二 · ADAPT

Fig. 11、Fig. 12：受限 LMS 與梯度投影法

實際上 Rxx 不知道，演算法只能用當下的抽頭電壓 X(k) 與輸出 y(k)。Frost 把未知的 RxxW 換成瞬時估計 X(k)y(k)，再讓每一步都回到約束平面：

受限 LMS　W(k+1) = P [ W(k) − μ y(k) X(k) ] + F ，　W(0) = F
梯度投影法　W(k+1) = W(k) − μ P y(k) X(k)

論文的模擬設定

6 位有效數字的浮點算術（HP-2116）、μ = 0.01、W(0) = F、200 次更新；兩種演算法吃完全相同的一組資料，和論文一樣。

輸出功率（對照 Fig. 11、Fig. 12 上圖）

和論文一樣有三條水平線：實線是最佳輸出功率，兩條虛線是最佳值加上式 (27) 的失調量上下界。輸出功率從 W(0) = F 的值一路往下掉，穩態在界附近抖動；兩種演算法的曲線幾乎重合，因為 200 次內梯度投影法累積的誤差還很小（論文 Sec. VII 最後一段）。初始與穩態之間的落差，就是處理器從輸出移除的雜訊功率。

論文兩張下圖的縱軸差了 10 倍（6×10−11 與 60×10−11），Fig. 12 圖說特別寫了「Note scale」。受限 LMS 每一步都加回 F，捨入造成的偏差在下一步就被拉回約束平面，所以誤差停在單一步捨入的大小；梯度投影法假設 W(k) 已經在約束平面上，偏差沒有被修正，一步步累積，像隨機漫步一樣離開約束平面。

對照程式：受限 LMS 與梯度投影法的主迴圈 
W = q(S.F);                              % W(0) = F；q() 把每個值捨入到 6 位有效數字
for k = 1:Nsnap
    x    = X(:, k);
    y(k) = q(W' * x);                    % 陣列輸出
    g    = q(mu * y(k) * x);             % μ × 瞬時梯度估計
    switch lower(algo)
        case 'clms'
            W = q(q(S.P * q(W - g)) + S.F);   % 式 (22)：投影，再加 F
        case 'gp'
            W = q(W - q(S.P * g));             % 式 (31)：只加投影後的梯度
    end
    Wh(:, k+1) = W;
end
out.Pout = sum(Wh .* (S.Rxx * Wh), 1);   % 真實輸出功率 Wᵀ R W
E        = S.C' * Wh - S.Fvec;
out.cerr = sum(E.^2, 1);                 % 約束誤差 ‖CᵀW − 𝓕‖²

約束解決什麼

項目受限 LMS（式 22）梯度投影法（式 31）
每步做什麼走一步、投影到 Σ、加 F 回到 Λ把投影後的梯度加到 W(k)，假設 W(k) 已在 Λ 上
輸出功率收斂到最佳值加失調量200 次內幾乎相同
捨入誤差每步被拉回約束平面，不累積沿平面平行移動，像隨機漫步累積
需要的先驗只要看向方向與想要的頻率響應；訊號與雜訊的統計都不需要

兩個演算法的差別只是式 (19) 最後一項 C(CTC)−1[𝓕 − CTW(k)]：完美算術下它是零，可以丟掉；數位實作下它就是自我修正，所以受限 LMS 可以無限期運行。
